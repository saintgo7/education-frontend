# Alpine.js Minimal - 미니멀 앱 개발 교육

Alpine.js를 사용한 가장 가벼운 인터랙티브 웹 개발 교육 프로젝트입니다.

## 🏔️ 주요 예제 (35+)

### 1. 기본 지시어 (12개)
- ✅ x-data - 데이터
- ✅ x-bind - 바인딩
- ✅ x-on - 이벤트
- ✅ x-text - 텍스트
- ✅ x-html - HTML
- ✅ x-model - 양방향 바인딩
- ✅ x-show - 표시/숨김
- ✅ x-if - 조건부 렌더링
- ✅ x-for - 반복
- ✅ x-transition - 트랜지션
- ✅ x-effect - 이펙트
- ✅ x-ref - 참조

### 2. 컴포넌트 패턴 (8개)
- ✅ Dropdown - 드롭다운
- ✅ Modal - 모달
- ✅ Tabs - 탭
- ✅ Accordion - 아코디언
- ✅ Tooltip - 툴팁
- ✅ Popover - 팝오버
- ✅ Carousel - 캐러셀
- ✅ Notification - 알림

### 3. 플러그인 (5개)
- ✅ Persist - 영속성
- ✅ Focus - 포커스
- ✅ Collapse - 접기/펼치기
- ✅ Intersect - 교차 관찰
- ✅ Mask - 입력 마스크

### 4. 고급 기능 (5개)
- ✅ Stores - 전역 상태
- ✅ Magic Properties - 마법 프로퍼티
- ✅ Custom Directives - 커스텀 지시어
- ✅ Alpine.data - 재사용 컴포넌트
- ✅ Alpine.store - 스토어

### 5. 실전 예제 (5개)
- ✅ Form Validation - 폼 검증
- ✅ Search - 검색
- ✅ Infinite Scroll - 무한 스크롤
- ✅ Dark Mode - 다크 모드
- ✅ Shopping Cart - 장바구니

## 🚀 시작하기

```bash
pnpm install
pnpm dev
pnpm build
```

## 🛠️ 기술 스택
- Alpine.js 3.13 (15KB)
- Vite 5
- Plain HTML/CSS

## 💡 Alpine.js의 특징
- ✅ 15KB의 작은 크기
- ✅ HTML에 직접 작성
- ✅ 빌드 과정 불필요
- ✅ jQuery 대체
- ✅ Tailwind CSS와 완벽 호환
