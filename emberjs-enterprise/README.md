# Ember.js Enterprise - 엔터프라이즈 웹 앱

## 📚 주요 예제 (10개)

1. ✅ **Components** - Ember 컴포넌트
2. ✅ **Routes** - 라우팅 시스템
3. ✅ **Controllers** - 컨트롤러
4. ✅ **Models** - 데이터 모델
5. ✅ **Services** - 서비스
6. ✅ **Helpers** - 헬퍼 함수
7. ✅ **Computed Properties** - 계산된 속성
8. ✅ **Actions** - 액션 처리
9. ✅ **Ember Data** - 데이터 관리
10. ✅ **Testing** - 테스트

🛠️ **기술 스택**: Ember.js 5, TypeScript
