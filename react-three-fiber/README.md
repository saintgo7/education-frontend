## 🚀 시작하기

```bash
pnpm install
pnpm dev
pnpm build
```

## 🛠️ 기술 스택
- React Three Fiber 8
- Three.js 0.160
- @react-three/drei (헬퍼)
- @react-three/rapier (물리)
- React 18
- TypeScript 5
