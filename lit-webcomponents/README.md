# Lit Web Components - 웹 컴포넌트 개발 교육

Lit을 사용한 표준 웹 컴포넌트 개발 교육 프로젝트입니다.

## 🔥 주요 예제 (40+)

### 1. 기본 컴포넌트 (10개)
- ✅ LitElement - 기본 엘리먼트
- ✅ Properties - 프로퍼티
- ✅ Events - 이벤트
- ✅ Styles - 스타일링
- ✅ Templates - 템플릿
- ✅ Lifecycle - 라이프사이클
- ✅ Slots - 슬롯
- ✅ ShadowDOM - 쉐도우 DOM
- ✅ Reactive - 리액티브
- ✅ Decorators - 데코레이터

### 2. 고급 패턴 (8개)
- ✅ Controllers - 컨트롤러
- ✅ Context - 컨텍스트
- ✅ Tasks - 비동기 태스크
- ✅ Directives - 지시어
- ✅ Mixins - 믹스인
- ✅ Composition - 컴포지션
- ✅ State - 상태 관리
- ✅ Actions - 액션

### 3. 스타일링 (6개)
- ✅ CSSProperties - CSS 프로퍼티
- ✅ CSSVariables - CSS 변수
- ✅ Themes - 테마
- ✅ HostStyles - 호스트 스타일
- ✅ AdoptedStylesheets - 채택된 스타일시트
- ✅ DynamicStyles - 동적 스타일

### 4. 폼 & 입력 (6개)
- ✅ FormAssociated - 폼 연결
- ✅ Validation - 검증
- ✅ CustomInput - 커스텀 입력
- ✅ FileUpload - 파일 업로드
- ✅ FormData - 폼 데이터
- ✅ TwoWayBinding - 양방향 바인딩

### 5. 통합 (5개)
- ✅ ReactIntegration - React 통합
- ✅ VueIntegration - Vue 통합
- ✅ AngularIntegration - Angular 통합
- ✅ Standalone - 독립 실행
- ✅ NPMPublish - NPM 배포

### 6. 성능 (5개)
- ✅ LazyLoading - 지연 로딩
- ✅ VirtualScroll - 가상 스크롤
- ✅ Memoization - 메모이제이션
- ✅ DOMEfficient - DOM 효율성
- ✅ BundleSize - 번들 크기

## 🚀 시작하기

```bash
pnpm install
pnpm dev
pnpm build
```

## 🛠️ 기술 스택
- Lit 3.1 (웹 표준)
- TypeScript 5
- Vite 5
- Web Components

## 💡 Lit의 장점
- ✅ 웹 표준 기반
- ✅ 프레임워크 독립적
- ✅ 작은 크기 (5KB)
- ✅ 모든 프레임워크와 호환
