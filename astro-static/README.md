# Astro Static - 정적 사이트 생성 교육

Astro를 사용한 초고속 정적 사이트 생성 교육 프로젝트입니다.

## 🚀 주요 예제 (40+)

### 1. 컴포넌트 & 레이아웃 (10개)
- ✅ AstroComponents - Astro 컴포넌트
- ✅ ReactIslands - React 아일랜드
- ✅ VueIslands - Vue 아일랜드
- ✅ Layouts - 레이아웃 시스템
- ✅ Slots - 슬롯 패턴
- ✅ Props - Props 전달
- ✅ CSS - 스타일링
- ✅ ClientDirectives - 클라이언트 지시어
- ✅ PartialHydration - 부분 하이드레이션
- ✅ ViewTransitions - 뷰 전환

### 2. 라우팅 & 페이지 (8개)
- ✅ Pages - 페이지 생성
- ✅ DynamicRoutes - 동적 라우트
- ✅ Pagination - 페이지네이션
- ✅ RSS - RSS 피드
- ✅ Sitemap - 사이트맵
- ✅ 404Page - 404 페이지
- ✅ Redirects - 리다이렉트
- ✅ Endpoints - API 엔드포인트

### 3. 콘텐츠 관리 (8개)
- ✅ MarkdownPages - 마크다운 페이지
- ✅ MDXComponents - MDX 컴포넌트
- ✅ ContentCollections - 콘텐츠 컬렉션
- ✅ Frontmatter - 프론트매터
- ✅ BlogSetup - 블로그 설정
- ✅ TagSystem - 태그 시스템
- ✅ Search - 검색 기능
- ✅ TableOfContents - 목차

### 4. 이미지 & 미디어 (5개)
- ✅ ImageOptimization - 이미지 최적화
- ✅ ResponsiveImages - 반응형 이미지
- ✅ LazyLoading - 지연 로딩
- ✅ VideoEmbed - 비디오 임베드
- ✅ IconSystem - 아이콘 시스템

### 5. SEO & 성능 (5개)
- ✅ MetaTags - 메타 태그
- ✅ OpenGraph - Open Graph
- ✅ Structured Data - 구조화된 데이터
- ✅ Performance - 성능 최적화
- ✅ Analytics - 분석 통합

### 6. 통합 & 배포 (4개)
- ✅ CMSIntegration - CMS 통합
- ✅ StaticDeploy - 정적 배포
- ✅ CloudflarePages - Cloudflare Pages
- ✅ Vercel - Vercel 배포

## 🚀 시작하기

```bash
pnpm install
pnpm dev
pnpm build
```

## 🛠️ 기술 스택
- Astro 4.0 (아일랜드 아키텍처)
- React 18 (선택적)
- Vue 3 (선택적)
- MDX (콘텐츠)
