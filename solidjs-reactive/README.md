# Solid.js Reactive - 리액티브 앱 개발 교육

Solid.js를 사용한 진정한 리액티브 웹 앱 개발 교육 프로젝트입니다.

## ⚡ 주요 예제 (45+)

### 1. 리액티비티 시스템 (10개)
- ✅ Signals - 시그널
- ✅ Effects - 이펙트
- ✅ Memos - 메모
- ✅ Stores - 스토어
- ✅ Resources - 리소스
- ✅ Context - 컨텍스트
- ✅ Batching - 배칭
- ✅ Computed - 계산된 값
- ✅ OnMount - 마운트 시
- ✅ OnCleanup - 클린업

### 2. 컴포넌트 (10개)
- ✅ FunctionalComponents - 함수형 컴포넌트
- ✅ Props - Props 전달
- ✅ Children - 자식 요소
- ✅ Refs - 참조
- ✅ Portal - 포털
- ✅ ErrorBoundary - 에러 바운더리
- ✅ Suspense - 서스펜스
- ✅ Show - 조건부 렌더링
- ✅ For - 리스트 렌더링
- ✅ Switch - 스위치 케이스

### 3. 라우팅 (5개)
- ✅ Router - 라우터 설정
- ✅ DynamicRoutes - 동적 라우트
- ✅ NestedRoutes - 중첩 라우트
- ✅ Navigation - 네비게이션
- ✅ LazyLoading - 지연 로딩

### 4. 상태 관리 (8개)
- ✅ LocalState - 로컬 상태
- ✅ GlobalState - 전역 상태
- ✅ PersistentState - 영속 상태
- ✅ AsyncState - 비동기 상태
- ✅ DerivedState - 파생 상태
- ✅ FormState - 폼 상태
- ✅ UIState - UI 상태
- ✅ ServerState - 서버 상태

### 5. 성능 최적화 (7개)
- ✅ FineGrainedReactivity - 세밀한 리액티비티
- ✅ LazyEvaluation - 지연 평가
- ✅ Memo - 메모이제이션
- ✅ CodeSplitting - 코드 스플리팅
- ✅ VirtualList - 가상 리스트
- ✅ DeferredUpdates - 지연 업데이트
- ✅ Reconciliation - 조정

### 6. 고급 패턴 (5개)
- ✅ RenderProps - 렌더 Props
- ✅ CompoundComponents - 복합 컴포넌트
- ✅ CustomDirectives - 커스텀 지시어
- ✅ Transitions - 트랜지션
- ✅ DynamicComponents - 동적 컴포넌트

## 🚀 시작하기

```bash
pnpm install
pnpm dev
pnpm build
```

## 🛠️ 기술 스택
- Solid.js 1.8 (진정한 리액티비티)
- TypeScript 5
- Vite 5
- Solid Router
