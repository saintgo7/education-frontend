## 📊 Core Web Vitals

### LCP (Largest Contentful Paint)
- 목표: 2.5초 이하
- 최적화: 이미지 최적화, 서버 응답 시간

### FID (First Input Delay)
- 목표: 100ms 이하
- 최적화: JavaScript 실행 최소화

### CLS (Cumulative Layout Shift)
- 목표: 0.1 이하
- 최적화: 이미지/비디오 크기 명시
