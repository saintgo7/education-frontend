# React Native Mobile - 모바일 앱 개발 교육

React Native와 Expo를 사용한 크로스 플랫폼 네이티브 모바일 앱 개발 교육 프로젝트입니다.

## 📱 주요 예제 (50+)

### 1. 기본 컴포넌트 (10개)
- ✅ CustomButton - 커스텀 버튼 컴포넌트
- ✅ Card - 카드 레이아웃
- ✅ Avatar - 아바타/프로필 이미지
- ✅ Badge - 뱃지/알림 표시
- ✅ Chip - 태그/칩 컴포넌트
- ✅ Divider - 구분선
- ✅ ListItem - 리스트 아이템
- ✅ SearchBar - 검색 바
- ✅ Rating - 별점 컴포넌트
- ✅ ProgressBar - 진행률 표시

### 2. 폼 & 입력 (8개)
- ✅ TextInput - 커스텀 텍스트 입력
- ✅ Select - 드롭다운 선택
- ✅ Checkbox - 체크박스
- ✅ RadioButton - 라디오 버튼
- ✅ Switch - 토글 스위치
- ✅ Slider - 슬라이더
- ✅ DatePicker - 날짜 선택
- ✅ FormValidation - 폼 검증

### 3. 네비게이션 (6개)
- ✅ StackNavigation - 스택 네비게이션
- ✅ TabNavigation - 탭 네비게이션
- ✅ DrawerNavigation - 드로어 네비게이션
- ✅ NestedNavigation - 중첩 네비게이션
- ✅ DeepLinking - 딥 링킹
- ✅ AuthNavigation - 인증 플로우

### 4. 애니메이션 (8개)
- ✅ FadeAnimation - 페이드 효과
- ✅ SlideAnimation - 슬라이드 효과
- ✅ ScaleAnimation - 스케일 변화
- ✅ RotateAnimation - 회전 효과
- ✅ SpringAnimation - 스프링 효과
- ✅ GestureAnimation - 제스처 기반
- ✅ SharedElement - 공유 엘리먼트
- ✅ LayoutAnimation - 레이아웃 애니메이션

### 5. 리스트 & 스크롤 (6개)
- ✅ FlatList - 평면 리스트
- ✅ SectionList - 섹션 리스트
- ✅ InfiniteScroll - 무한 스크롤
- ✅ PullToRefresh - 당겨서 새로고침
- ✅ VirtualizedList - 가상화 리스트
- ✅ SwipeableList - 스와이프 리스트

### 6. 모달 & 오버레이 (5개)
- ✅ Modal - 기본 모달
- ✅ BottomSheet - 바텀 시트
- ✅ ActionSheet - 액션 시트
- ✅ Alert - 알림 다이얼로그
- ✅ Toast - 토스트 메시지

### 7. 미디어 & 파일 (6개)
- ✅ ImagePicker - 이미지 선택
- ✅ Camera - 카메라 접근
- ✅ VideoPlayer - 비디오 재생
- ✅ AudioPlayer - 오디오 재생
- ✅ FileUpload - 파일 업로드
- ✅ ImageGallery - 이미지 갤러리

### 8. 센서 & 하드웨어 (5개)
- ✅ Geolocation - 위치 정보
- ✅ Accelerometer - 가속도계
- ✅ Gyroscope - 자이로스코프
- ✅ Biometric - 생체 인증
- ✅ HapticFeedback - 햅틱 피드백

### 9. 네트워킹 & 스토리지 (6개)

- ✅ BundleOptimization - 번들 최적화

## 🚀 시작하기

```bash
# 의존성 설치
pnpm install

# 개발 서버 시작
pnpm start

# iOS 실행
pnpm ios

# Android 실행
pnpm android
```

## 📚 학습 경로

1. **기본 컴포넌트** (1주) - UI 컴포넌트 기초

3. **애니메이션** (1주) - 인터랙티브 애니메이션
4. **네트워킹** (1주) - API 연동
5. **최적화** (1주) - 성능 튜닝
