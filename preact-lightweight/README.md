# Preact Lightweight - 경량 앱 개발 교육

Preact를 사용한 초경량 웹 앱 개발 교육 프로젝트입니다.

## 🪶 주요 예제 (38+)

### 1. 기본 컴포넌트 (10개)
- ✅ FunctionalComponents - 함수형 컴포넌트
- ✅ ClassComponents - 클래스 컴포넌트
- ✅ Hooks - 훅
- ✅ Props - Props 전달
- ✅ State - 상태 관리
- ✅ Refs - 참조
- ✅ Context - 컨텍스트
- ✅ Fragments - 프래그먼트
- ✅ Portals - 포털
- ✅ ErrorBoundary - 에러 바운더리

### 2. 라우팅 (6개)
- ✅ Router - 라우터
- ✅ Routes - 라우트 정의
- ✅ Navigation - 네비게이션
- ✅ DynamicRoutes - 동적 라우트
- ✅ NestedRoutes - 중첩 라우트
- ✅ LazyRoutes - 지연 로딩

### 3. 성능 최적화 (8개)
- ✅ SmallBundle - 작은 번들 (3KB)
- ✅ FastRender - 빠른 렌더링
- ✅ Memoization - 메모이제이션
- ✅ VirtualList - 가상 리스트
- ✅ LazyLoading - 지연 로딩
- ✅ CodeSplitting - 코드 스플리팅
- ✅ TreeShaking - 트리 쉐이킹
- ✅ Compression - 압축

### 4. SSR (4개)
- ✅ ServerRendering - 서버 렌더링
- ✅ Hydration - 하이드레이션
- ✅ Streaming - 스트리밍
- ✅ StaticGeneration - 정적 생성

### 5. 상태 관리 (5개)
- ✅ LocalState - 로컬 상태
- ✅ GlobalState - 전역 상태
- ✅ Signals - 시그널
- ✅ Zustand - Zustand 통합
- ✅ AsyncState - 비동기 상태

### 6. React 호환성 (5개)
- ✅ ReactCompat - React 호환
- ✅ preact/compat - 호환 레이어
- ✅ ReactLibraries - React 라이브러리 사용
- ✅ Migration - React에서 마이그레이션
- ✅ Aliases - 별칭 설정

## 🚀 시작하기

```bash
pnpm install
pnpm dev
pnpm build
```

## 🛠️ 기술 스택
- Preact 10.19 (3KB)
- TypeScript 5
- Vite 5
- Preact Router

## 💡 Preact의 장점
- ✅ 3KB의 작은 크기
- ✅ React와 동일한 API
- ✅ 빠른 성능
- ✅ React 라이브러리 호환
