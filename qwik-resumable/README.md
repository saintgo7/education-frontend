# Qwik Resumable - Resumable 앱 개발 교육

Qwik을 사용한 즉시 상호작용 가능한 웹 앱 개발 교육 프로젝트입니다.

## ⚡ 주요 예제 (42+)

### 1. Resumability (8개)
- ✅ ResumeOnClient - 클라이언트 재개
- ✅ Serialization - 직렬화
- ✅ LazyExecution - 지연 실행
- ✅ NoHydration - 하이드레이션 없음
- ✅ ProgressiveLoading - 점진적 로딩
- ✅ OnDemandJS - 온디맨드 JS
- ✅ Prefetching - 프리페칭
- ✅ Speculative - 추측 로딩

### 2. 컴포넌트 (8개)
- ✅ Components$ - 컴포넌트
- ✅ useSignal - 시그널
- ✅ useStore - 스토어
- ✅ useTask - 태스크
- ✅ useResource - 리소스
- ✅ useContext - 컨텍스트
- ✅ Slots - 슬롯
- ✅ useRef - 참조

### 3. 라우팅 (6개)
- ✅ QwikCity - Qwik City
- ✅ FileBasedRouting - 파일 기반 라우팅
- ✅ Layouts - 레이아웃
- ✅ Navigation - 네비게이션
- ✅ DynamicRoutes - 동적 라우트
- ✅ Prefetching - 프리페칭

### 4. 데이터 로딩 (6개)
- ✅ routeLoader$ - 라우트 로더
- ✅ server$ - 서버 함수
- ✅ routeAction$ - 라우트 액션
- ✅ Form - 폼 처리
- ✅ Streaming - 스트리밍
- ✅ Caching - 캐싱

### 5. 최적화 (7개)
- ✅ AutomaticCodeSplitting - 자동 코드 스플리팅
- ✅ ZeroJavaScript - 제로 JavaScript
- ✅ InstantInteractive - 즉시 상호작용
- ✅ OptimisticUI - 낙관적 UI
- ✅ ParallelDownload - 병렬 다운로드
- ✅ SmallBundles - 작은 번들
- ✅ TreeShaking - 트리 쉐이킹

### 6. 고급 기능 (7개)
- ✅ SSR - 서버 사이드 렌더링
- ✅ SSG - 정적 사이트 생성
- ✅ EdgeFunctions - 엣지 함수
- ✅ Middleware - 미들웨어
- ✅ SEO - SEO 최적화
- ✅ i18n - 국제화
- ✅ Analytics - 분석

## 🚀 시작하기

```bash
pnpm install
pnpm dev
pnpm build
```

## 🛠️ 기술 스택
- Qwik 1.3 (Resumable)
- Qwik City
- TypeScript 5
- Vite 5

## 💡 Qwik의 혁신
- ✅ 0ms TTI (Time To Interactive)
- ✅ 하이드레이션 불필요
- ✅ 자동 지연 로딩
- ✅ 최소 JavaScript
